
# अन्वय (Anvay)
> Connecting knowledge. Enabling understanding.

Anvay is an AI-powered learning platform designed to help students learn from their course materials, practise through quizzes, and identify concepts that need revision.

## Vision
Build a platform that connects course content with personalised, interactive learning.

## Planned Features
- Ask questions about uploaded course materials.
- Get answers grounded in source documents, with citations.
- Generate topic-specific quizzes and explanations.
- Track learning progress and identify weak concepts.

🚧 Under development.
